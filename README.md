# HyperOpen

**HyperOpen** 是一款专为 **小米澎湃 OS（Xiaomi HyperOS）** 打造的屏下指纹快捷方式（FOD QuickOpen）深度增强 Xposed / LSPosed 模块。

本模块通过接管并重构系统界面（`com.android.systemui`）中的指纹长按快捷面板，将系统原生单调的扇形有限快捷方式升级为**圆形蜂窝阵列、弧面扇形、空心圆环**样式，同时支持图标自定义排版、多套配置与在线双市场、跨用户双开直选、启动日志审计以及丰富的配置参数修改，带来兼具澎湃光学质感、丝滑鱼眼交互与极高自由度的指纹快捷启动体验。

## 📦 环境要求与安装使用

### 环境要求
- **系统版本**：小米澎湃 OS（Xiaomi HyperOS，Android 10 / API 29 及以上），设备需支持屏下指纹并已在系统设置中开启指纹快捷功能。
- **框架环境**：已安装 **LSPosed**（推荐）或其他兼容 Xposed API 82+ 的框架。
- **可选权限**：
  - **Root 权限**：用于设置页「重启系统界面」一键生效、Root Shell（`su -c`）指令执行，以及跨用户受限 Activity 的兜底唤醒。
  - **存储读取权限**：用于在应用内实时预览页加载当前系统真实桌面壁纸。
  - **网络权限（可选 / 按需）**：仅在用户主动打开「配置市场 / 快捷市场」浏览、预览、导入或上传共享条目时访问内置在线市场接口；SystemUI 宿主端与日常离线使用完全零联网。

### 使用步骤
1. 前往 [Releases](https://github.com/qmryqmm/HyperOpen/releases) 页面下载最新版本的 APK 并安装。
2. 打开 **LSPosed 管理器**，启用 **HyperOpen** 模块，并勾选作用域：**系统界面 (`com.android.systemui`)**。
3. 打开 **HyperOpen** 应用，根据喜好调整视觉参数与快捷方式列表（也可在配置市场或快捷市场直接导入社区配置）。
4. 在模块「设置」页点击 **「重启系统界面」**（或通过 LSPosed 重启 SystemUI 作用域）完成首次挂载。
5. 使用指纹解锁手机时，**保持手指按压在指纹传感器区域**即可唤出 HyperOpen 快捷面板，滑动至目标图标松手即可触发。
   > 💡 **提示**：首次挂载生效后，日常修改快捷方式或调整外观参数均通过跨进程 Provider 与广播**实时热生效**，无需再次重启系统界面。

## ✨ 核心特性

### 1. 多布局样式与物理鱼眼交互
- **三种布局样式自由切换**：
  - **蜂窝阵列布局**（默认）：打破原生数量限制，多个快捷项目以中心对称的圆形蜂窝结构紧密排布；
  - **空心同心圆环布局**：中心保持留空，图标沿单圈同心圆环排布；
  - **弧形扇面布局**：150° 弧带排布，单弧放不下时自动转为双弧。
- **扇区触发模式（空心圆环专属）**：快捷方式 1 ~ 6 个时启用，图标沿单圈圆周均分排布，该圆以内为中心取消区，圆外按图标数量均分为等角度扇形，滑入哪个扇形就选中哪个图标（不再依赖欧氏距离，图标稀疏时也不会误触）；分隔虚线颜色 / 透明度 / 虚线节奏 / 粗细均可调，且向视界外延伸至屏幕边缘，关掉圆形底衬后屏上只留虚线与图标。该模式下自动禁用自定义排版；7 个及以上回退常规同心圆环。
- **图标数量动态上限**：「图标数量」滑块上限与图标显示区域直径、图标尺寸、间距等几何参数实时联动钳制（弧形扇面不设几何上限），容量随布局自动变化，不会出现放不下的配置。
- **面板与文件夹紧凑度分离**：主面板与文件夹子项图标紧凑程度支持独立调节（均支持负值紧凑），并对子项圆环排布进行了居中弧段优化。
- **动态鱼眼缩放**：手指在指纹区域滑动时，焦点图标与邻近气泡具备基于距离影响半径的连续鱼眼放大、透明度过渡与 Z 轴自动置顶防遮挡效果。**「鱼眼最大放大倍率」在全部布局下生效**，文件夹展开后的二级气泡同样走完整鱼眼曲线。
- **可视化拖拽排序**：在「快捷项目」管理页内嵌整体蜂窝预览，支持长按图标直接拖拽调整排布顺序并实时磁吸保存。

### 2. 可调布局与动效
- **独立「动效」页**：配置界面提供「布局 / 动效 / 外观 / 图标 / 震动」分页，布局页按「面板布局与几何」「图标 / 文件夹布局与几何」分组，动效页按「面板动效」「图标 / 文件夹动效」分组。
- **面板动画与防竞态保护**：可分别调整展开动画类型、展开时长与错峰、收起动画类型、收起时长与错峰，以及选中回弹倍率；展开类型支持原生直线、弹性绽放、淡入缩放，收起类型支持向心收拢、淡出缩小、选中回弹、原生直线回收，并针对快速连按退场选中回弹增加了防竞态死锁保护。
- **文件夹子项布局与压暗过渡**：固定使用单圈圆环按数量与展开方向居中排布成连续圆弧段（默认背离指纹展开），整体显示范围、固定方向 / 自定义相对角度、最小间距与子项尺寸均可调；文件夹展开压暗与关闭恢复支持平滑渐变过渡。
- **文件夹子项动画**：支持弹性扇形弹出、原生直线飞出、原地淡入放大、波浪弹出，以及向中心收拢、原地淡出缩小、反向波浪收拢；展开 / 收起时长、错峰、起始缩放和弹性强度均可调。

### 3. 双光学材质与多维高斯模糊渲染
- **双材质引擎**：
  - **高斯模糊材质**：实时局部毛玻璃模糊渲染，通透还原背景色彩层次（已消除 API 33+ 双重模糊与高斯模糊下图标四角矩形溢边问题，修改配置后首次展开面板即刻生效）。
  - **柔光玻璃材质（液态玻璃）**：具备次表面立体散射、菲涅尔动态梯度描边与选中激活外发光辉光动效；不支持柔光玻璃材质的设备在应用相关配置时支持**自动降级为高斯模糊并智能补偿模糊半径**。
- **解耦气泡材质与留白比例**：图标气泡材质开关与内部留白比例解耦，支持在开启气泡材质的同时将留白设为 `0%` 紧贴图标本体；全局材质参数可一键跟随，移除 Ghost 模糊半径 20px 强制下限与双重透明度过暗问题。
- **全方位参数可调**：支持唤醒全屏模糊遮罩透明度、图标显示区域直径、垂直偏移量（Offset Y）、底衬开关与独立高斯模糊半径、鱼眼影响半径及顶部提示胶囊背景开关。
- **跨版本兼容适配与容错**：运行时按「方法名 + 参数个数」探测并缓存系统 `BlurUtils#applyBlur` 的 2 参 / 3 参签名；全屏高斯模糊与全屏压暗独立包裹容错，互不连带失效。

### 4. 指纹解锁与蓝牙解锁唤出体验
- **等待阈值可调节**：Hook `android.os.Handler#postDelayed` 精准拦截 `MiuiGxzwManager#dismissGxzwView` 的展开 Runnable，将「指纹解锁后需按住传感器多久才唤出面板」做成可调项（`0 ~ 2000 ms`，默认 `500 ms` 位置不干预系统原生判定，`0 ms` 为解锁后立即弹出）。
- **支持蓝牙解锁后长按唤出**：连接信任蓝牙设备解锁屏幕的场景下，长按指纹区域同样支持正常唤出 HyperOpen 快捷面板。

### 5. 配置管理与在线双市场（配置市场 + 快捷市场）
- **多套本地配置管理**：内置配置管理界面，支持多套配置的新建、复制、重命名、拖拽排序、导入 / 导出，支持**「仅应用快捷方式」**或应用完整配置，智能识别未保存改动；配置详情中的快捷项清单支持文件夹子项展开预览。
- **在线配置市场与快捷市场**：
  - **配置市场**：专注纯外观参数共享（与快捷方式解耦），可关联推荐配套快捷包；支持「仅预览外观」或「与配套快捷包一起预览」。
  - **快捷市场**：原生支持「单个快捷方式」与「快捷包」分类上传与筛选（`全部 / 单个快捷方式 / 快捷包`）；支持搜索快捷包内的顶层项与文件夹子项，并在详情页自动展开命中文件夹。
- **一设备一作者与官方徽章**：支持本机作者身份绑定、官方认证徽章展示与作品管理，删除关联快捷包时自动解除配置绑定。
- **纯内存沙箱临时预览与一键启动测试**：市场配置均在纯内存沙箱中临时预览（不覆盖、不污染当前本地配置，预览页支持「松手执行」开关）；快捷市场列表与详情页支持一键「启动测试」（Root / Shell 等高危动作触发二次确认）。

### 6. 高度自由的快捷方式、跨用户双开与 Root Shell 引擎
- **多类型动作与预设**：支持启动任意已安装应用、启动 Activity（内置 Activity 浏览器自动填参，结构化 Action / Data / Component / Package / Extra 编辑）、Intent URI、Shell 指令及内置十余项高频官方动作预设（微信/支付宝扫一扫、付款码、收款码、乘车码、相机、手电筒等）。
- **跨用户空间（双开 / 手机分身）智能选择与可靠执行**：
  - 自动探测本机真实存在的双开 / 分身用户空间，并在快捷方式编辑页实时感知目标应用安装状态；
  - 应用选择器与 Activity 选择器新增**「双开 / 分身」分页**，选中双开应用时自动联动对应启动用户，无需手动猜测 User ID；
  - 执行链路升级：免 Root 启动应用优先通过 `LauncherApps` 直启目标用户，Root 启动 Activity 按目标用户空间解析组件，避免跨用户误回退或 `ActivityNotFoundException` 异常崩溃。
- **全新 Root Shell 执行引擎与锁屏防冻结桥接**：
  - 重构 Root Shell 为标准 `ProcessBuilder("su", "-c", cmd)` 调用并内置多路径兜底与 CRLF 换行清洗，彻底修复含中文参数、双引号或复杂 Intent 的 Shell 指令失效问题；
  - 锁屏状态下通过 `SettingsProvider` 跨进程保活防冻结桥接执行，并发调度线程池升级，避免多任务串行阻塞。
- **顺手的编辑体验**：参数编辑界面保存后不自动退出，可连续调整并随时点击「立即启动测试」验证；排版界面返回键退出时弹窗询问是否保存改动。

### 7. 三套矢量图标库与解耦式图标样式（Miuix 125 + Glass 精选 24 + Remix 129）
- **三套完整矢量图标库**：
  - **Miuix 官方图标库**：内置 125 款 Miuix 风格矢量图标，支持 **5 档线条粗细**自由切换；
  - **Glass 精选图标库**：内置 24 款 HyperOS Glass 风格矢量图标，覆盖 AI 扫描、小爱、勿扰/静音、支付卡证、日程、投屏、设备连接与系统入口，同样支持 **5 档线条粗细**；
  - **Remix 图标库**：内置 129 款 Remix Icon 矢量图标（24×24 原生 PathData），默认快捷项目全量采用矢量图标，跨进程一致渲染。
- **矢量图标颜色与纯色底垫解耦**：在双 Tab 图标设置弹窗中，可分别独立配置**矢量图标前景色**、**圆形纯色底垫颜色**及 **连续不透明度（`5% ~ 100%`）**（旧版底垫配置自动无损迁移）。
- **单快捷方式独立裁切**：应用图标支持按单个快捷方式独立选择**抗锯齿圆形裁切**或**自适应外扩满铺**方案。

### 8. 快捷方式启动日志（排错与审计）
- 在「软件设置」页新增 **「快捷方式启动日志」** 查看入口，覆盖锁屏面板、应用内预览、编辑页测试、快捷市场测试等全部触发来源。
- 日志采用独立设备加密（DE）存储，自动循环保留**最近 100 条**记录。
- 以卡片列表呈现每次执行摘要，点击卡片可查看完整详情：**启动类型（App / Activity / URI / Shell 等）、触发来源、目标用户、执行时间、完整启动参数、成功/失败状态及详细报错信息**，方便快速定位跨用户权限、Shell 语法或 Intent 异常。

### 9. 1:1 实时真机壁纸预览
- 支持实时加载系统当前桌面壁纸作为背景，在模块内提供与真实指纹唤醒界面完全一致的全屏交互预览，所有滑块与开关均支持热重载即时预览。
- **全屏与组件模糊叠加**：组件材质模糊与全屏背景模糊按高斯近似 `sqrt(r_fullscreen² + r_component²)` 叠加，App 内预览与 SystemUI 真机渲染共用同一套组合半径。
- **按住后连续滑动与松手执行**：关闭「面板常驻」时按住指纹按钮即可连续滑动选中，右上角「松手执行」开关默认关闭，开启后可直接在预览页按真机行为触发动作。

### 10. 系统级稳定性守护、安全鉴权与 Direct Boot
- **SystemUI 崩溃安全模式（SafetyGuard 守护）**：若模块 Hook 引发 `SystemUI` 在 5 分钟内连续异常崩溃达 2 次，运行期将**即时拆解全部 Hook** 并自动切入安全模式，恢复原生指纹面板，杜绝卡锁屏或无限重启；支持在设置页查看状态、切换总开关与一键重置。
- **跨进程鉴权与性能优化**：加固 `SettingsProvider` 跨进程调用鉴权，修复 SystemUI 启动与热更新防死循环机制，大幅削减主线程 IO 并优化图标缓存与配置防抖。
- **Direct Boot 直接启动支持**：配置与状态数据统一落设备加密（DE）存储，重启手机未解锁时即可完成安全校验与 Hook 挂载，开机即生效；并发出 `ACTION_USER_UNLOCKED` 补装兜底。
- **一键恢复默认参数**：设置页提供「恢复默认参数」入口并配备二次确认弹窗，一键重置全部参数与快捷方式列表。
- **原生澎湃风格 UI**：基于 **Miuix Compose** 构建，支持跟随系统 / 浅色 / 深色模式、**Monet 动态取色**以及**胶囊悬浮底栏**。
